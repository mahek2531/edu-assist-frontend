# Edu Assist Frontend

Frontend repository for Edu Assist.

The Vite app lives in `edu-assist-frontend`.

## Local Setup

```powershell
cd edu-assist-frontend
npm install
npm run dev
```

Create `edu-assist-frontend/.env` from `edu-assist-frontend/.env.example`.

For local backend development:

```env
VITE_API_BASE=http://localhost:8080
```

Do not commit `.env`, `node_modules`, or `dist`.
